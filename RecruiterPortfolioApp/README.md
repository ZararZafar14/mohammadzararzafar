# Recruiter Portfolio — Kotlin Android

A recruiter-focused Android portfolio app demonstrating practical Kotlin development, SQLite persistence, Material 3, CRUD, project presentation and career information.

## Features
- Modern recruiter-focused home dashboard
- Featured projects and full project list
- Skills and proficiency dashboard
- Career snapshot / recruiter view
- Contact form with SQLite persistence
- Add projects with CRUD-ready local storage
- Message management
- Local SQLite database with projects, skills, messages and settings tables
- Kotlin + AndroidX + Material 3
- No Room dependency

## Architecture
UI -> MainActivity -> PortfolioDbHelper -> SQLite

## Run
Open `RecruiterPortfolioApp` in Android Studio and sync Gradle. Build and run on an Android emulator or device.

## Portfolio talking points
This project demonstrates Kotlin, Android lifecycle basics, SQLite, CRUD, data modeling, Material UI, local persistence and recruiter-oriented UX.
